# Luma Calendar development updates

This repository distributes development builds of Luma Calendar for Android.
The application source is maintained separately.

## Download and update

Download the APK from the latest release once a build has been published.
The app requires an ARM64 device running Android 8.0 or later.

After installing an updater-enabled build, open **Settings → Check for updates**
in Luma. Choose **Download update**, allow installation from Luma if Android
requests it, and approve the Android installation dialog.

Install updates over your existing app. Do not uninstall Luma to update it:
uninstalling removes its local calendar and settings.

Each release contains the signed APK, update.json, and SHA256SUMS.txt. These are
development builds and may contain unfinished features. APK downloads are public.
No user calendar data, API keys, signing keys, or private build logs belong here.

The update feed becomes available after the first successful published build:

https://github.com/Videniye/luma-calendar-updates/releases/latest/download/update.json
